| Элемент | Синтаксис | Результат |
| :--- | :--- | :--- |
| **Жирный** | `**Текст**` или `__Текст__` | **Текст** |
| *Курсив* | `*Текст*` или `_Текст_` | *Текст* |
| ~~Зачеркнутый~~ | `~~Текст~~` | ~~Текст~~ |
| ***Жирный курсив*** | `***Текст***` | ***Текст*** |
| Подсветка кода | `` `код` `` (инлайновый) | Используйте `GET` запрос |

Разделители двоеточия `:` управляют выравниванием текста в колонках.


| Метод API | Эндпоинт | Описание | Статус |
| :--- | :---: | :--- | ---: |
| Левое выравнивание | По центру | По умолчанию | Правое выравнивание |

| `POST` | `/v1/users` | Создать нового пользователя | Депрекейтнутый |



## 7. Цитаты и Оповещения (Blockquotes & Admonitions)

### Стандартная цитата:

> **Важно:** При проектировании REST API всегда используйте существительные во множественном числе для ресурсов (например, `/users`, а не `/getUser`).

> [!WARNING]

## 8. Экранирование и Спецсимволы (Escaping)

Если нужно отобразить символ, который является частью разметки Markdown, используйте обратный слэш `\`:

\* отобразит просто звездочку `*`, а не сделает текст курсивом.

\# отобразит решетку, а не создаст заголовок.
