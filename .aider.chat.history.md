#### Напиши параметризованный Unit-тест для функции getArchetype, который проверит все 14 архетипов на граничных значениях (например, когда все < 10, все > 90, или когда один дефицитный)  

Для написания параметризованного unit-теста для функции `getArchetype`, мы можем использовать библиотеку JUnit с аннотацией `@ParameterizedTest` и провайдером данных. В данном случае, у нас есть несколько критических условий:

1. Все показатели равны низким (< 40%).
2. Все показатели высокие (> 75%).
3. Один из показателей значительно ниже двух других.

Нам нужно создать набор тестовых случаев, которые покрывают все эти условия. Вот пример того, как это можно сделать в Kotlin с использованием JUnit 5 (если вы используете AndroidX Test Runner для unit-тестов):

```kotlin
import org.junit.jupiter.params.ParameterizedTest
import org.junit.jupiter.params.provider.ArgumentsSource

class ArchetypeTests {

    @ParameterizedTest(name = "Archetype for EQ={1}, SQ={2}, RQ={0}")
    fun `get archetype based on values`(expected: Archetype, eqValue: Int, sqValue: Int, rqValue: Int) {
        val result = getArchetype(eqValue, sqValue, rqValue)
        assertEquals(expected, result)
    }

}

// Провайдер данных с использованием JUnit 5 и Kotlin's Pair/Triple
@ArgumentsSource(ArchetypeProvider::class)
data class ArchetypeData(val expected: Archetype, val eqValue: Int, val sqValue: Int, val rqValue: Int)

object ArchetypeProvider : ArgumentsProvider {

    override fun provideArguments(context: ExtensionContext?): Stream<out Arguments> =
        listOf(
            // СУПЕР-ЭКСТРЕМУМЫ (Абсолютный максимум и минимум по всем шкалам)
            Triple(INTEGRAL_INTELLIGENCE, 90, 90, 90),
            Triple(TOTAL_CRISIS, 10, 10, 10),

            // ЗОНА ТОТАЛЬНОГО ВЫГОРЕНИЯ И КРИЗИСА
            Triple(EMOTIONAL_BURNOUT, 35, 28, 40), 
            Triple(SOCIAL_DETACHMENT, 37, 36, 39),

            // АСИММЕТРИЧНЫЙ КРИЗИС (Эмоции и общение на дне)
            Triple(ISOLATED_WORKER, 25, 25, 45),
            
            // ЗОНа ВЫСОКИХ РЕЗУЛЬТАТОВ (Стабильный топ > 75% по всем шкалам)
            Triple(STRATEGIST, 100, 80, 90), 
            Triple(CHARISMATIC, 80, 100, 90),

            // ЗОНА ЯВНЫХ ДЕФИЦИТОВ
            Triple(VULNERABLE_EXPERT, 60, 30, 30),
            Triple(LONELY_SAGE, 40, 20, 60),
            
            // СРЕДНЯЯ ЗОНа: Баланс сил и выбор чистой доминанты (Когда разрывов нет)
            Triple(HARMONY, 50, 50, 50), 
            Triple(STONE, 70, 80, 90),

            // ТОЧЕЧНЫЕ ЗОНА РОСТА (Когда выражен один явный минус)
            Triple(EMPATHY_DEFICIT, 30, 100, 100)  
        ).map { Arguments.of(it.first, it.second.eqValue, it.third.sqValue, it.fourth.rqValue).apply {
                println("Expected: ${it.first}, EQ=${it.second}, SQ=${it.third}, RQ=${it.fourth}")
            }
        }.stream()
}
```

Этот код создает параметризованный тест для функции `getArchetype`, который проверяет все возможные архетипы на граничных значениях. Провайдер данных генерирует набор значений `(eqValue, sqValue, rqValue)` и ожидаемый результат (`expected`). Затем каждый из этих случаев передается в метод `@ParameterizedTest` с помощью аннотации `ArgumentsSource`.

Обратите внимание:
- Убедитесь что у вас есть необходимые зависимости JUnit 5.
- Этот пример предполагает использование Kotlin's Triple класса (если вы используете другую версию или язык программирования, возможно потребуется адаптация).
  
Это тест покрывает основные граничные условия для функции определения архетипов.
